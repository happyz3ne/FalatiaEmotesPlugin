# FalatiaEmotes Plugin (Paper 26.3)

Серверний плагін для моду [Falatia Emotes](https://github.com/happyz3ne/FalatiaEmotes). Створений для синхронізації емоцій під час гри на серверах minecraft. 

## Встановлення

1. Перемістіть `FalatiaEmotesPlugin-1.0.0.jar` до папки `plugins/` та перезапустіть сервер.
2. Щоб побачити емоції у грі для цього вам необхідно мати встановлений мод Falatia Emotes

## Серверні емоції

Для встановлення серверних емоцій вам необхідно їх перемістити у папку серверу за шляхом `plugins/FalatiaEmotesPlugin/emotes/`

Після чого використайте команду на сервері `/falatiaemotes reload`, щоб перезавантажити емоції. І емоції автоматично відправляться гравцям на сервері, і вони зможуть їх використовувати.

## Конфігурація

Конфіг плагіну знаходиться за шляхом `plugins/FalatiaEmotesPlugin/config.yml`.

| Параметр | Значення | Опис |
|---|---|---|
| `enabled` | `true` | Якщо встановити параметр `false`, кожен гравець бачитиме лише власні емоції, а серверні емоції будуть недоступні. |
| `cache-mb` | `16` | Обсяг пам'яті, виділений для кешування спільних файлів емоцій. |
| `uploads-per-minute` | `20` | Обмеження на кількість програвань нових емоцій від одного гравця за хвилину. |

## Команди

- `/falatiaemotes reload` — перезавантаження плагіну і конфігурації

**Пермішени:** `falatia.emotes.admin` (за замовчуванням доступний адміністраторам серверу).

## Збірка

Для створення збірки плагіну використовуйте команду:

```bash
./gradlew build
```

Готовий плагін буде знаходитися за шляхом `build/libs/FalatiaEmotesPlugin-1.0.0.jar`.

Для збірки потрібна версія Java 25.
